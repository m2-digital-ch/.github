# M2 Digital GmbH

**Smart, Simple, Scalable.** SAP consulting and software solutions from one partner, based in
Tägerwilen, Switzerland.

We advise companies on SAP S/4HANA, build targeted extensions close to the standard and develop
our own software. Some of the tools we build for ABAP and SAP GUI are published here as open
source.

## What you find here

Our public repositories are ABAP add-ons for SAP S/4HANA. They are installed with
[abapGit](https://abapgit.org), released under the MIT license and come with an English and a
German README, an architecture description and step-by-step installation instructions.

| Repository | What it does |
|---|---|
| [abap-sd-flexible-workflow-gui](https://github.com/m2-digital-ch/abap-sd-flexible-workflow-gui) | Shows the approval status of the S/4HANA flexible workflow for credit memo requests directly in VA03: a header tab with all workflow runs and steps, plus an optional status button in the toolbar. |

## How we work

- **Standard first.** Where the SAP standard is enough, we use it. Where an extension adds value,
  we build it upgrade-safe.
- **Open for contributions.** Code, comments and object names are in English so that the SAP
  community can take part; UI texts are translated.
- **Checked on every push.** Each repository runs [abaplint](https://abaplint.org) in GitHub Actions.
